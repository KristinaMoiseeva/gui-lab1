# Лабораторная работа №1 — PyQt5

## Описание

Программа разработана в рамках первой лабораторной работы по дисциплине, связанной с проектированием графического интерфейса.

Приложение реализовано на Python с использованием библиотеки PyQt5.

В главном окне расположены:

- надпись `QLabel`;
- кнопка **«Кнопка 1»**;
- кнопка **«Кнопка 2»**.

### Кнопка 1

При нажатии на кнопку текст в `QLabel` заменяется изображением из файла `assets/label.png`.

### Кнопка 2

При нажатии открывается диалог выбора PNG-файла. Выбранное изображение используется как фон и маска окна: прозрачные области PNG становятся прозрачными областями окна, благодаря чему форма окна меняется.

Для демонстрации в каталоге `assets` находится файл `window_shape.png`.

## Используемые технологии

- Python 3
- PyQt5
- механизм сигналов и слотов Qt
- `QLabel`
- `QPushButton`
- `QFileDialog`
- `QPixmap`

## Установка

Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Для Windows:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Принцип работы

Обработчики кнопок подключаются через механизм сигналов и слотов PyQt5:

```python
self.button_image.clicked.connect(self.show_image_in_label)
self.button_shape.clicked.connect(self.load_window_shape)
```

Метод `show_image_in_label()` загружает изображение в `QLabel`.

Метод `load_window_shape()` открывает диалог выбора PNG, загружает изображение через `QPixmap` и применяет его alpha-канал как маску окна.

## Результат

В результате реализовано графическое приложение, в котором пользователь может:

1. заменить текстовую надпись изображением;
2. загрузить PNG-файл и изменить форму окна в соответствии с прозрачностью изображения.
